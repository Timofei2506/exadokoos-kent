# ExadokoOS для кента · готовый образ

Здесь лежит **загрузочный ISO ExadokoOS 1.0** — операционная система, которая
ставится на ноутбук вместо Windows и сама следит за тем, что скачивается.

> Сборка приватная, для одного человека. Не распространять.

---

## Скачать ISO (с телефона)

1. Открой вкладку **Releases** справа (или снизу на телефоне)
2. В последнем релизе в разделе **Assets** нажми
   `ExadokoOS-1.0.0-installer-kde-amd64.iso` (~1 ГБ) — скачается на телефон
3. Рядом лежит `.sha256` — по желанию проверь целостность

## Записать на флешку (с телефона, без компьютера)

1. Поставь **EtchDroid** — F-Droid или Play Market (root не нужен)
2. Флешку в телефон через **OTG-переходник**
3. EtchDroid → **«Write raw image»** → выбери ISO → выбери флешку → **Write**
4. Не дёргай переходник, пока идёт запись (5–15 минут)

Всё, что было на флешке, сотрётся.

## Поставить на ноутбук

1. Флешку в ноутбук → включи → сразу жми **F12** (или F2 / F9 / Del) →
   выбери загрузку с USB
2. Установщик сам покажет список дисков и спросит, **какой стирать**:
   - набери имя диска (например `/dev/nvme0n1`) для подтверждения
   - если на диске есть разделы (Windows кента) — набери слово `СТИРАЙ`
3. Дальше всё само: разметка → Debian 13 → ExadokoOS → GRUB (20–45 минут,
   **нужен интернет**: Wi-Fi или кабель)
4. Перезагрузка → ноутбук грузится в ExadokoOS

Если ноутбук не грузится с флешки: зайди в BIOS и выключи Secure Boot /
поставь USB первым в порядке загрузки.

## Что появится после первой загрузки

- Плашка **«Кент, большой брат следит за тобой 👀»** — закрой её, больше не вылезет
- Рабочий стол KDE Plasma, обои ExadokoOS
- Папки `Обучение` и памятки на рабочем столе («Игры в ExadokoOS», «О системе»)
- Steam, Lutris, Heroic, Proton — игры
- LibreOffice, Anki, VSCodium, Python — учёба
- AnyDesk — удалённый доступ (поднимется сам и получит ID)
- **ExadokoGuard** — проверяет каждый скачанный файл (ClamAV + YARA +
  VirusTotal по хэшу). Если файл похож на вирус — придёт всплывашка
  «⚠️ файл подозрительный». **Качать не запрещает и ничего не удаляет.**

## Вход

| Кто | Логин | Пароль |
|---|---|---|
| Кент | `kent` | задаётся при установке (автологин включён) |
| Владелец | `exoadmin` | в файле `/etc/exadoko/secrets.conf` на машине (права 0600) |

У кента нет `sudo` — специально: выключить защиту и слежку он не сможет.

## Команды для владельца

```bash
sudo exadoko-status        # здоровье системы
sudo exadoko-log           # что скачано, какие вердикты
sudo exadoko-log --risky   # только подозрительное
sudo exadoko-log --follow  # живой эфир
sudo exadoko-connect       # AnyDesk ID + пароль + QR-код
sudo exadoko-digest --print  # сводка за сутки
sudo exadoko-update check  # обновления
```

## Обновления

Образ обновляется так же, как ставился: новый ISO появится в Releases этого
репозитория. Внутри системы:

```bash
sudo exadoko-update check     # есть ли что новое
sudo exadoko-update apply     # обновить систему и ExadokoOS
sudo exadoko-update from-bundle /путь/ExadokoOS-1.1.0.exoupdate   # офлайн
```

Патчи безопасности Debian ставятся сами, без спроса и без перезагрузки.
